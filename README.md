PUBLISH ON GITHUB PAGES
1. Open your repository's Code tab.
2. Upload index.html and README.md to the repository root.
3. If GitHub asks, commit the changes to the main branch.
4. In Settings > Pages, choose Deploy from a branch, branch main, folder /(root), then Save.
5. Wait for deployment and open your Pages URL.

SECURITY NOTE
This is a static educational website. It does not include a real admin panel, user accounts, database, or live tournament registration. Do not put passwords, API keys, or private data in this file. A genuinely private admin system needs a trusted server/backend and server-side authentication.
