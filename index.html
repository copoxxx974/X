01 / INTELLIGENCE

AI & Prompt Engineering

Learn to ask better questions, plan projects and use AI tools responsibly.

Open learning path
  • Start with one clear goal and provide useful context.
  • Ask for steps, examples and a format you can use.
  • Check important facts instead of trusting every output.
  • Protect personal data and never share passwords.
  • Practice: ask an AI to plan a small project, then review the plan.
⌘
02 / DEVELOPMENT

Coding & Code Mode

Understand programming basics and use coding assistants to build and debug projects.

Open learning path
  • Learn variables, conditions, loops, functions and data structures.
  • Choose Python for beginner logic or HTML/CSS/JavaScript for websites.
  • Describe the expected behavior before asking for code.
  • Run small tests, read errors and change one thing at a time.
  • Practice: build a simple calculator or to-do list.
⌬
03 / WEB WORLDS

Create a Website

Plan, design, code and publish a responsive website from phone or computer.

Open learning path
  • Plan the pages and write the content first.
  • Use HTML for structure, CSS for design and JavaScript for interactions.
  • Keep filenames and file paths exactly consistent.
  • Test on mobile and desktop; check links and image loading.
  • Publish a static site with GitHub Pages; use a backend for private data.
◈
04 / PLAY SMART

Gaming Skills & Setup

Improve controls, performance, teamwork, practice habits and game sense.

Open learning path
  • Set comfortable sensitivity and control layout.
  • Prioritize stable frame rate and a reliable connection.
  • Practice one skill at a time and review mistakes.
  • Use team voice chat respectfully and agree on simple callouts.
  • Take breaks and protect your account with unique passwords.
⌁
05 / COMPETITION

Esports & Team Building

Build a team, define roles, prepare for tournaments and play fairly.

Open learning path
  • Choose one game and agree on the team’s goal.
  • Recruit reliable players; assign roles and a team captain.
  • Create a practice schedule and review matches together.
  • Read tournament rules, eligibility, check-in and match formats.
  • Use official registration channels; never pay unknown organizers without verification.
⬡
06 / DIGITAL DEFENSE

Cybersecurity & Safety

Learn defensive security, privacy basics, scam awareness and legal ethical practice.

Open learning path
  • Use a password manager and enable multi-factor authentication.
  • Check links, sender details and unexpected attachments.
  • Learn networking, operating systems and basic security concepts.
  • Practice only in authorized labs and systems you own or have permission to test.
  • For cybercrime, preserve evidence and report through official channels.
